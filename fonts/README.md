# Fonts for AutoMatte: Text on Surface
SIL Open Font License 1.1 fonts from github.com/google/fonts (pinned commit and file list in the Miracle
`text/fonts_to_fetch.md`). Each family's licence ships next to its files as `OFL-<family>.txt`. Without a font the node
falls back to Pillow's built-in font and flags the run for review.
